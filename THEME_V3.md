# Theme v3 · Light / Neon

- **Light:** original warm-ivory colors and original yellow-on-hover cards are restored, with no global light-theme override.
- **Dark:** midnight background, subtle neon cyan / lavender / pink accents; each home card transitions its border and foreground color on hover.
- **Switch:** only Home, an unboxed, outline-only light bulb centered above Projects / Archive / About.
- **Profile:** original light character and alternate hooded dark character automatically switch as before.
- **Persistence:** theme saved in sessionStorage across pages in the same tab; new browsing sessions start light. Return Home to toggle it.
- **Accessibility:** in Dark mode the line-art bulb uses a pale stroke so it remains visible against the dark background. Reduced-motion is respected.

Theme palette and the button: `assets/css/theme-switch.css`; behavior: `assets/js/theme-switch.js`.
